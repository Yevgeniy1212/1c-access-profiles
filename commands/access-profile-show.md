# access-profile-show

Паспорт профиля. Только чтение.

## Шаги

1. Проверить `.roles-access.yaml`. Нет — `/access-init`, остановиться.
2. Если имя профиля не передано — сначала показать список (`/access-profiles-list`)
   либо спросить имя через AskQuestion.
3. Выполнить:

   ```
   python .cursor/1c-access-profiles/scripts/profiles_list.py --details "<имя профиля>"
   ```

4. Пересказать результат понятным языком:
   - сколько ролей и какие (сгруппировать: поставляемые / доработки / роли запуска);
   - какие виды доступа ограничены, какие «все разрешены»;
   - есть ли ограничения по значениям (организации, склады, подразделения).

## Как объяснять пользователю

- **Виды доступа** — это то, по чему ограничивается видимость данных.
  «Все разрешены» = без ограничения; «ограничены» = видит только указанные значения
  (например, только свою организацию).
- **Значения доступа** — конкретные организации/склады, доступные этому профилю.
  Если их нет, а вид доступа ограничен, — пользователь не увидит ничего.
- **Роли запуска** (`ЗапускТонкогоКлиента` и подобные) без них пользователь
  не войдёт в программу.

## Запреты

- Не изменять данные.
- Не интерпретировать названия ролей «на глаз» — только то, что вернул скрипт.

## Дальше

`/access-profile-analyze <имя>` — какие объекты и на каком уровне даёт профиль.
